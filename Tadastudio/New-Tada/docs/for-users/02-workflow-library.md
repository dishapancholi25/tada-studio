# Workflow Library

The Library is a shared collection of ready-to-use agent workflows. Browse, search, and run them directly, or use them as a starting point by cloning into your workspace.

---

## Browsing the Library

Click **Library** in the left navigation to open it.

<img width="1435" height="777" alt="image" src="https://github.com/user-attachments/assets/ec5071b5-44f4-4d71-8b87-b2d5e1a692a7" />

Each card shows the workflow's name, description, category tags, and complexity level (Beginner / Intermediate / Advanced).

---

## Filtering and Searching

Use the search bar to find workflows by name or keyword. Use the category and tag filters on the left to narrow results.

<img width="1382" height="712" alt="image" src="https://github.com/user-attachments/assets/1822d54c-11a0-4f49-aa27-0222dfdaee19" />

---

## Cloning a Workflow

To edit a library workflow, click **Clone**. This copies it into your personal workspace where you can modify it freely without affecting the shared original.

<img width="1512" height="778" alt="image" src="https://github.com/user-attachments/assets/3769163b-f166-4248-9d5c-99eb3f6140e9" />

---

## Importing an Agent

To add a new workflow to the Library from a JSON configuration, click **Import Agent** in the top-right corner of the Library page.

<img width="382" height="371" alt="image" src="https://github.com/user-attachments/assets/e785ef25-b93b-4228-90d2-ad3715ec8300" />

Paste your JSON, review or adjust the metadata (name, category, tags, icon colour), and confirm. See [Importing Agents](./08-importing-agents.md) for the full JSON schema reference.
