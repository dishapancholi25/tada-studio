# Keyboard Shortcuts

TADA Studio provides cross-platform keyboard shortcuts for common canvas and workflow actions. Press **?** at any time on the workflow canvas to open the shortcuts reference dialog.

---

## History

| Action | Windows / Linux | macOS |
|--------|----------------|-------|
| Undo last action | `Ctrl + Z` | `⌘ + Z` |
| Redo last action | `Ctrl + Y` | `⌘ + Shift + Z` |
| Redo (alternative) | `Ctrl + Shift + Z` | `⌘ + Shift + Z` |

---

## Canvas

| Action | Windows / Linux | macOS |
|--------|----------------|-------|
| Copy selected node(s) | `Ctrl + C` | `⌘ + C` |
| Paste copied node(s) | `Ctrl + V` | `⌘ + V` |
| Delete selected node(s) or connection(s) | `Delete` | `⌫` |
| Delete (alternative) | `Backspace` | `⌫` |
| Deselect all nodes | `Escape` | `Esc` |
| Fit view to canvas | `Ctrl + 0` | `⌘ + 0` |

---

## Navigation

| Action | Input |
|--------|-------|
| Zoom in/out | Scroll wheel |
| Pan canvas | Click and drag on empty space |
| Move node with children | `Ctrl + Drag` (Windows/Linux) / `⌘ + Drag` (macOS) |

## Tips

- **Multi-select**: Click and drag on empty canvas space to draw a selection box around multiple nodes.
- **Precise positioning**: Hold `Shift` while dragging to constrain movement to a single axis.
- **Quick node deletion**: Select a node and press `Delete` — no confirmation dialog for single nodes.
- **Connection deletion**: Click on a connection (edge) to select it, then press `Delete` to remove it.
