# Logo Assets Directory

Place the following logo files in this directory:

## Required Logos (SVG or PNG format preferred)

1. **sharepoint.svg** - Microsoft SharePoint logo
2. **microsoft-graph.svg** - Microsoft Graph logo  
3. **salesforce.svg** - Salesforce logo
4. **jira.svg** - Atlassian Jira logo
5. **pdf.svg** - PDF or document generation icon

## Recommended specifications

- Format: SVG (preferred) or PNG with transparent background
- Size: 24x24px or 32x32px
- Color: Original brand colors or monochrome versions

## Download sources

- Microsoft logos: <https://developer.microsoft.com/en-us/brand>
- Salesforce: <https://www.salesforce.com/company/legal/intellectual/>
- Atlassian Jira: <https://www.atlassian.com/company/news/press-kit>
- Or use icon libraries like:
  - Simple Icons: <https://simpleicons.org/>
  - Devicon: <https://devicon.dev/>

## Alternative: Use CDN links

You can also use CDN-hosted logos by updating the img src to:

- `https://cdn.jsdelivr.net/gh/devicons/devicon/icons/[service]/[service]-original.svg`
- Or Simple Icons CDN: `https://cdn.jsdelivr.net/npm/simple-icons@v9/icons/[service].svg`
